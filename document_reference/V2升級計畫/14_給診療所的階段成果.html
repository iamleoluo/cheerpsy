1這份文件怎麼用

從 §2 的三個觀念開始讀，那三件事決定了整個系統的邏輯，看懂之後其他頁都說得通。 接著 §3 是櫃檯的一天，照著走一遍就知道日常長什麼樣。 §5 是我們最希望你們花時間的一節——那是你們十一份合約在系統裡的實際設定， 請逐份核對，設定錯了後面所有金額都會錯。

系統裡現在有一整年的模擬資料 不是空的畫面。每個工作日約 53 場現場諮商、一年一萬九千多筆預約、 一千一百多位個案、十一家機構合約、一萬五千多筆場次紀錄。 所以打開診間日曆看到的是一間忙碌診所的樣子，而不是空白表格。

資料全部是假的（姓名、電話、身分證都是生成的），可以隨便點、隨便改、隨便試， 不會弄壞任何東西。改壞了跟我們說一聲，重新生成一份就好。
我們最想知道的 不是「好不好看」，而是——哪一步比你們現在的做法更麻煩？ 系統做了很多防呆，而防呆的代價是多按幾下。哪裡防過頭了、哪裡少問了一句， 只有每天在用的人知道。

2三個核心觀念

2.1 出席驅動：按了「已到」才有帳

一筆帳什麼時候產生，取決於櫃檯有沒有按下「已到」，不是取決於時間到了沒。

以前的做法現在
什麼時候記帳預約時間一過就自動記按下「已到」的那一刻
人沒來還是會記一筆，要再去改不會有帳；登記「未到」還會把機構補助次數還回去
漏處理的看不出來，因為都自動記了一直留在「待報到」，一眼看得到
為什麼改 舊系統有個很嚴重的問題：只要打開帳冊頁面，系統就會自動把逾時未報到的預約標成「已到」、 產生場次紀錄、並扣掉個案的機構補助次數。等於「看一眼帳」就幫個案簽了到、用掉了他一次補助。 而且完全沒有痕跡。這個已經移除了。

代價是櫃檯一定要按。漏按的話那格會一直留在「待報到」——可以在日報表用「執行日結」一次補登， 但請先確認那些人真的有來；沒來的應該登記未到，不是日結。

2.2 報價快照：歷史金額是事實，不是重算出來的

機構案的金額在建立預約當下就依那份合約的費率規則算好，並把「當時算出來的答案」存進那筆預約。

  • 之後就算改了費率，已經發生的場次金額不會被改動。
  • 所以費率可以放心調整，不會影響已經送出去的請款單。
  • 對帳時看到的金額，就是當初約定的金額，不會因為後來改了設定而對不起來。

2.3 顏色只表達狀態，不表達操作

格子的底色代表「這件事現在怎麼了」；按鈕一律是黑白的。 這樣眼睛才能靠顏色掃一整天，不會被按鈕的顏色干擾。

顏色意思什麼時候出現
灰底今天不用再碰了自費：收款＋開據都完成／月結：按完「已到」就變灰／機構案：還要行政提醒全部勾完
黃底剩最後一次這個機構補助只剩一次。收錢前務必確認金額，下一次就要換方式
紅底未到未到不會變灰，它要一直被看見
白底還要處理待報到、已到未收、已收未開據

角色、付費別、年齡層這種屬性不用顏色——字面上已經寫著「管理員」「機構」「兒青」了， 再給它一個綠色只會讓人誤以為是「完成」。

3櫃檯的一天

3.1 早上：先看今天有什麼

  1. 開 營運總覽，上方是當日統計（預約數、已報到、未到、當日已收、尚待收款）， 下方是今日待辦佇列——待報到、已到未收款、已收款未開據、文件待確認、機構額度將盡、退回補件。
  2. 每一項都可以直接點過去處理，處理完會自動從清單消失。
  3. 掃過一遍之後切到 診間日曆，那一頁整天都不用關。

3.2 個案來了：報到三步驟

步驟按什麼會發生什麼 / 要注意
①「已到」系統當下建立場次紀錄、扣掉機構補助次數、算出要收多少錢
②「收款 $X」選現金或匯款；匯款要填末五碼（對帳時要用）。機構全額補助的不會出現這一步，會顯示「機構請款 · 免收」
③「開立收據」選收費名目 → 收據編號自動產生。月結個案不需要當場開據

三步都在格子上完成，不用換頁。目前走到哪一步就只長出那一步的按鈕，不會四個都排出來讓人選錯。

3.3 初診個案（格子會標「初診」）

從媒合轉進來的新個案，第一次來的時候還沒有病歷號。那一格的按鈕會直接寫「已到 · 補個資」—— 所以你按之前就知道要請對方拿證件。

  1. 按「已到 · 補個資」。
  2. 表單只問還缺的欄位：身分證、出生日期、連絡電話三個必填，需求表已經填過的（通常是電話）不會再問一次。
  3. 按「產生病歷號並完成報到」→ 系統產生 8 碼病歷號、個案轉正式、媒合案自動結案。
  4. 接著就跟一般場次一樣走收款、開據。

3.4 人沒來

  1. 按「未到」→ 選原因：個案來電請假、臨時取消、未聯繫上、其他。
  2. 可以填備註與催繳方式。
  3. 確認後：機構補助次數會還回去；預約狀態維持「已預約」供對帳追蹤（不會變成取消）。
  4. 初診未到還要多選一項後續處理：轉預約（同一位心理師重排）、派案（換人重新媒合）、轉媒合結案。

3.5 收工前：對帳

  1. 開 日報表 / 對帳，確認現金總額跟抽屜對得起來。
  2. 匯款的逐筆核對末五碼跟存摺明細。
  3. 切到「未收」，看今天已到但沒收到錢的——那些會自動進應收帳冊，不會擋住結帳。
  4. 有漏按「已到」的，用「執行日結」一次補登。
  5. 零用金在同一頁的第二個分頁，順便記一下當天的支出。

3.6 每週 / 每月

頻率做什麼
每週應收帳冊看未收與機構應收；核銷案總表看有沒有可以送出的；文件分頁看有沒有等核對的
每月機構合約看額度用得如何；數據分析看進案統計與月報表；產生心理師月結酬勞
不定期媒合管理處理新的詢問；流失預警看有沒有該聯絡的個案

心理師酬勞為什麼分三區 A · 抽成：診所收全額，再依抽成率拆給心理師——這是收入。
B · 回饋制：鐘點費由心理師直接向機構請領，這一區是他應回繳診所的部分——是扣項。
C · 場地費扣回：心理師個人借用診間的場地費（督導模式 B）——也是扣項。

三種錢的方向不一樣。混在同一張表會讓人把扣項讀成收入，所以分開列、各自有小計。 另外還有外出保底：外展場次抽成不足保底金額時系統自動補足。
現場由櫃檯按，視訊外展由心理師自己按 現場個案的已到／未到一律由櫃檯在診間日曆登錄；視訊與外展因為櫃檯看不到現場， 由心理師自己按。管理員兩種都能按（覆蓋用）。

7系統會幫你們擋掉的錯

這些都是實際發生過、而且用眼睛看不出來的錯誤。列在這裡不是要邀功， 是因為知道系統擋了什麼，才知道哪些事可以放心不用再人工複查。

會被擋下來的事不擋的話會怎樣
還沒收到錢就開收據收據編號一開出去就是憑證。曾經有 81 筆還欠著錢的紀錄照樣顯示收據編號
同一筆場次被收進兩個核銷案會向機構重複請款
取消或未到卻沒還補助次數個案的額度會愈用愈少，而且看不出來少在哪
加時改了金額，機構總額度沒跟著調合約總額度會以為還有錢，實際上已經超支。金額池只有一個總數，這種偏差只有在快見底時才會浮現
沒填機構個案代號就送核銷機構退件。而且以前代號漏填就永久補不了，那些個案的核銷整條走不下去
加時撞到下一位系統不會自動把下一位擠掉，會請你聯絡行政處理——把衝突交給人去喬比較安全
診間、場地租借、雲燈教室互相撞時段三種佔用空間的事共用同一套檢查，不可能重複佔用
初診沒登記身分證就報到產不出病歷號，個案會卡在暫存狀態，後面的核銷全部走不了
費率規則的「其餘情況」排在中間排在它後面的規則永遠輪不到，於是所有人都用到同一個價
已收款之後改時數金額會跟已經收的錢對不起來。要先作廢那筆帳款
背後有一組自動對帳的檢查 系統裡有 25 條跨表核對，每次資料異動後全部跑一遍：額度加起來對不對、 酬勞總額跟明細合不合、收據號有沒有重複、場次金額的機構那半加個案那半等不等於總額…… 任何一條對不上就會叫。這不是你們會看到的畫面，但它是「帳不會悄悄算錯」的來源。

8常見狀況怎麼處理

狀況怎麼做
忘記按「已到」，隔天才發現日報表 / 對帳 →「執行日結」可以補登當天的。更早的到「預約總表 → 待報到」，把日期範圍拉回去找
按錯「已到」，其實那個人沒來作廢那筆帳款，額度會退回。然後重新登記未到
收據開錯了在那一格的明細裡作廢（要填原因），再重開一張。作廢與重印沿用同一個編號的不同狀態碼，軌跡會留著
個案的機構額度用完了，但還要繼續談三個選擇：合約專頁「延長額度」（要機構核准）、改成自費、或改用別的方案
合約總額度（國軍、15-45青壯）見底掛在那份合約下的所有人都會被擋。要跟機構追加額度，然後在合約專頁調整上限
機構個案代號當初漏填合約專頁 → 個案與額度分頁 → 補登。不用重建個案
核銷案送出前發現收錯場次作廢那個核銷案（要填原因），裡面的場次會退回「尚未收納」，重新建一個
心理師文件交了但格式不對合約專頁 → 文件分頁 →「退回補件」並填原因。心理師端會標紅排最上面，看得到原因
談超過時間了格子明細 →「調整實際時數」。金額依單價等比重算，個案自付固定不動，多的由機構吸收。撞到下一位會被擋
個案臨時請假格子明細 →「個案請假」。跟「未到」是不同的事，請假是事前知會
初診當天個案沒帶證件目前身分證是必填（沒有它產不出病歷號）。可以先不報到，等證件補齊再處理——這一點如果實務上不可行，請告訴我們
費率要調整機構合約 → 該方案 →「編輯費率」。只影響之後的預約，已建立的不會被改動
心理師抽成比例要改系統管理 → 帳號管理 → 就地編輯。不影響已經算過的歷史月份（用的是當時的快照）

9等你們決定的兩件事

只有兩件，但都卡著，愈早決定愈好。

項目要決定什麼
日報表的欄位目前的日報表 / 對帳是第一版。第二版要放哪些欄位、怎麼分類，取決於你們財務實際怎麼結。我們會先做一版給你們指著改——描述一個還不存在的表格很難，改一個已經在眼前的容易得多
收據編號格式系統已做成可切換，預設是 §6 的新版格式。我們會印一張實際的樣張給你們看，確認之後改設定就好，不用改程式
另外想確認的兩件小事 ① 初診報到時身分證是必填（產病歷號需要）。如果實務上常常有人沒帶證件，我們需要另外想辦法。
② 上面 §5 那 11 份合約的設定，有沒有哪一份跟你們手上的合約對不起來。

10怎麼開始試用

10.1 十五分鐘的快速導覽

  1. 診間日曆，看今天。有三十幾格還沒報到，隨便挑一格按「已到」，走完收款、開收據三步。
  2. 找一格標「初診」的，按「已到 · 補個資」，看病歷號怎麼產生出來。
  3. 找一格黃底的（剩最後一次）和一格紅底的（未到），看看跟其他格子的差別。
  4. 日報表 / 對帳，看剛才那筆有沒有出現在當天的現金裡；順便看一下零用金分頁。
  5. 應收帳冊，三個分頁各看一下——特別是「機構應收」的「尚未收納」。
  6. 機構合約，挑一家點進去，看額度長條、核銷案、費率規則。試著按「編輯費率」看看（不用存檔）。
  7. 用心理師帳號登入，看「我的今日」「文件確認」「我的酬勞」。

10.2 完整的驗收走查

計畫書裡有兩份操作腳本，本來就是當驗收依據寫的：

  • 04 操作樣本_行政櫃檯 —— 35 個步驟
  • 05 操作樣本_心理師 —— 31 個步驟

照著走，在哪一步卡住就停下來講。比起「請試用看看然後給意見」， 指著一個具體的步驟說「這裡不對」有用得多。

10.3 系統裡也有說明

左側選單最下面的「操作指南」是內建的說明書，14 個模組， 比這份文件更細——會講到按鈕層級、每個欄位的意思、以及出錯時怎麼辦。 另外個案管理與數據分析兩頁的右上角有「說明」按鈕，會在側邊展開該頁的重點。
