0如何使用本文件

這是行政櫃檯完整操作樣本，作為完成品驗收的核心依據。分兩部分：Part 1 是逐步操作腳本，每一步列出「操作 → 預期畫面 → 觸發的 API → DB 變化」，可逐項打勾；Part 2 是可點互動原型，點擊畫面元素會高亮對應的腳本列，驗收時可一邊點一邊對。

交叉檢核聲明本文件出現的每一個 API 呼叫，都能在 02 架構變更規格 §5 找到定義；每一個 DB 欄位變化，都能在 02 §1 找到對應表格。若驗收時發現對不上，代表 02 或本文件其中一份需要修正。
