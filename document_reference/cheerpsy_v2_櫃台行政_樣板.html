結帳方式如何計算（核心）
  • 此欄不是固定設定值，而是「當前或下次預約會採用的結帳方式」，由系統即時推算。
  • 判斷順序：
    ① 個案是否有有效中的機構方案且尚有可用額度 → 顯示 機構（並標示 已用/總數）。
    ② 額度用罄或方案過期 → 自動回落到個案的自費設定（月結／次結／多次結）。
  • 同時有多個機構方案時，一個方案用完才使用下一個（依有效期先到先用）。
  • 已結案個案顯示結案當下的結帳方式，不再變動。
額度將盡的提示（介面已呈現）
  • 最後一次時該列整列標黃，標籤顯示 3/3 最後一次，並附一行說明「下次自動轉自費 · 月結」。
  • 個案詳情頁頂端另有橫幅提醒，行政與心理師都看得到。
  • 操作欄出現 設定下次結帳，可改月結／次結／多次結，或改掛新的機構方案。
  • 同一提醒會出現在營運總覽待辦與診間日曆該時段方塊上，確保櫃檯收款時不會用錯金額。
其他規則
  • 預警流失：超過 45 天無預約自動標記，可在此直接結案。
  • 結案：跳出結案原因視窗；結案後取消所有未來預約並釋出機構已預留／已預約額度（見機構方案清冊）。
  • 換心理師：由行政操作；原心理師即失去該個案歷史紀錄的查看權，新心理師與管理者可看完整歷程。
  • 伴侶案以一筆合併收費，計為一案。

⚙️ 頁面邏輯與互動設計 — 重點：額度三態（已預留 / 已預約 / 已使用）
三種額度狀態的定義
  • 已預留：個案符合資格、第一次預約時（尚未初診）即先把個人上限全數預留。例如方案是一年 3 次，加入當下就先預留 3 次，避免方案被別人用光。
  • 已預約：已排定但尚未執行的預約所佔用的額度＝計畫中會用到的量。
  • 已使用：已執行完畢的場次，進入核銷流程。
  • 三者恆等式：已使用 + 已預約 + 已預留 = 個人上限（介面用一條三色長條呈現）。
額度流轉
  • 加入方案 → 全數進已預留（例 0/0/3）。
  • 排一次預約 → 預留轉預約（0/1/2）。
  • 報到按已到 → 預約轉使用（1/0/2）。
  • 按未到或取消預約 → 預約退回預留。
  • 個案結案 → 取消所有未來預約，已預留＋已預約全數釋出回方案總池，狀態轉「已結案」並移入封存清冊。
擋預約與提示
  • 預約時同時檢查個人上限與方案年度總量，任一不足即擋下並提示改自費。
  • 剩最後一次時，個案在清單標最後一次，診間日曆該方塊加紅框。
  • 方案已過期／已用罄時不可再新增個案；已在其中者只能用完既有額度。
  • 防呆：同一人在同一方案不可重複加入。
  • 已結案／已失效／已用罄的個案自動轉入封存清冊。
待確認 ① 預留是否要設有效期（例如加入後 30 天內未初診就自動釋回），避免額度被長期佔住。
② 個案暫停（非結案）時，已預留額度要保留還是釋出？
③ 跨年度時未用完的額度處理方式：歸零重算，或可展延。
④ 方案年度總量快滿時（如剩 5 次），是否要對行政發出預警。

建立核銷案：三步驟（重點）
  • ① 選機構 / 方案：同一機構的不同方案必須分開建案（窗口與額度不同）。
  • ② 選期間：系統顯示上次核銷案的結束日，並建議接續起日。
    ・有缺口 → 警告「X 天未被納入，可能漏請款」
    ・有重疊 → 警告「恐重複請款」
    ・兩者皆為警告不阻擋，行政可自行判斷後繼續。
  • ③ 選人：勾選的單位是「人」不是場次。因為同機構不同個案可能分屬不同核銷案（分批請款、社工窗口不同），必須逐一挑選。
  • 不可單挑場次：勾了某人，其在該期間內所有符合的場次整組納入。展開只能唯讀檢視，沒有個別勾選框 — 避免漏請與重複請。
  • 已被其他核銷案佔用的個案鎖定不可選（顯示所屬案號）。
資料齊備的三條路
  • 正常：心理師提交 → 行政核對 → 該筆齊備。
  • 豁免：機構免繳文件時，行政［豁免本案資料］整案跳過心理師提交；可［恢復需繳資料］撤銷。
  • 退回補件：行政發現錯誤 → 填退回原因 → 清除該筆的心理師確認與行政核對 → 回「待提交」並通知心理師。
  • 退回是單筆操作，不影響同案其他紀錄；但只要有一筆未齊備，整案就無法轉「待送出」。
  • 全部齊備 → 系統自動由「收集中」轉「待送出」。
作廢與款項回退
  • 任一階段皆可作廢，需原因 + 密碼，並留稽核軌跡。
  • 作廢後：紀錄脫離本案、付款狀態退回 未核銷、回到可核銷池可重新建案。
  • 已開立收據一併作廢（編號 -3）。
  • 機構額度不受影響 — 額度在報到「已到」時就已由已預約轉已使用，與核銷無關。
  • 心理師酬勞不受影響 — 酬勞依已執行場次計算，與是否請款成功脫鉤。
  • 已實際撥款後才作廢會額外警告，退款需另行處理。
  • 作廢案保留在列表（灰階）供稽核；編號不回收，重開取新流水號。
