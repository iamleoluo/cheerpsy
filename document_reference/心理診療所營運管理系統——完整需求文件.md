# 心理診療所營運管理系統——完整需求文件

**文件版本：** v2.2
**最後更新：** 2026-05-11
**文件編號：** 03162876

---

## 一、系統目標

1. **營運數位化：** 自動化預約、排診、計費與核銷流程。
2. **管理決策化：** 提供診間利用率、個案流失率及心理師收入之量化報表。
3. **財務精準化：** 建立預約單與收據的關聯，確保帳務與診療紀錄一致。
4. **操作極簡化：** 心理師端的操作流程盡可能精簡，複雜邏輯由系統與行政承接。

---

## 二、角色權限定義

| 角色 | 可操作範圍 | 不可操作範圍 |
|------|------------|--------------|
| 心理師 | 建立／取消當日及未來預約、查看個人門診名單、查看個人收入分析 | 修改已發生（前一日以前）的任何紀錄 |
| 行政櫃台 | 處理排診、提醒電訪、收費登載、產製收據、金流追蹤、執行核銷、取消當日及未來預約 | 修改已發生的預約或帳務 |
| 診所管理員 | 以上全部，加上修改已發生日期的帳務與紀錄 | 無 |

> **資料隱私原則：** 行政人員僅能看到收費與基本聯絡資訊；心理師僅能看到個案諮商摘要，無法存取其他心理師資料。

## 四、模組一：個案管理系統

### 性質
靜態固定型資料庫，於個案**初診時建立**，基本資料不頻繁異動。

### 欄位內容

| 欄位 | 說明 |
|------|------|
| 個案 ID | 系統自動產生之唯一識別碼 |
| 個案姓名 | |
| 身份證字號 | AES 加密儲存，符合個資法規範 |
| 出生年月日 | |
| 性別 | |
| 聯絡電話 | |
| 緊急聯絡人 | |
| 初診日期 | |
| 經費來源 | 自費 / 機構轉介（決定後續帳務分類） |
| 轉介機構名稱 | 機構轉介填入；自費留空 |
| 負責心理師 | 直接整合於個案資料，不另設對應表單 |
| 個案狀態 | 初診 / 持續諮商 / 暫停中 / 已結案 / 流失 |

> 完整欄位清單待後續補充確認。

### 流失預警機制
系統自動篩選超過指定天數未回診且未結案的個案，產出追蹤清單供行政處理。天數門檻由管理員設定。

## 五、模組二：預約與執行管理

### 性質
本模組為整個系統的**動態核心**。心理師在此建立預約，系統依預約狀態的變化自動驅動後續模組（流水帳、空間釋出、金流追蹤）。

---

### 5.1 心理師操作流程

對心理師而言，系統只有**兩個動作**：

| 動作 | 說明 |
|------|------|
| **建立預約** | 選個案、選時段（可單次或批次）、填金額 → 完成 |
| **取消預約** | 若個案未到或取消 → 當日內點選取消 → 完成 |

> 其餘所有流程（執行確認、金流追蹤、報表產出）完全由系統與行政處理，心理師不需介入。

---

### 5.2 建立預約

#### 單次 vs. 批次預約

| 情境 | 操作方式 |
|------|----------|
| 初診 | 單次預約，填入時段、空間、金額 |
| 複診 | 批次預約，一次建立 N 筆（如固定每週三 14:00，共 6 次） |

批次預約時，系統預設每筆金額相同，心理師可**個別覆寫**特定場次金額（如初診費與複診費不同）。

#### 預約建立欄位

| 欄位 | 說明 |
|------|------|
| 預約單號 | 系統自動產生，格式：R-YYYYMMDD-心理師代號-流水號 |
| 個案 | 從個案管理系統選取 |
| 心理師 | 登入者自動帶入 |
| 諮商類型 | 實體 / 線上 / 家訪 |
| 空間 | 實體才需選；線上與家訪自動略過 |
| 日期與時段 | 單次或批次設定 |
| 金額 | 批次預設同一金額，可個別調整 |
| 心理師應得酬勞 | 自動計算（金額 × 70%），不需心理師操作 |
| 診所應得收入 | 自動計算（金額 × 30%），不需心理師操作 |

---

### 5.3 預約狀態機

預約建立後，系統依下列規則自動流轉：

```
          ┌──────────────────────────────┐
          │          已建立預約            │
          └───────────────┬──────────────┘
                          │
           ┌──────────────┴──────────────┐
           │                             │
    時間到期且未取消               心理師當日手動取消
           │                             │
           ▼                             ▼
    ┌─────────────┐             ┌──────────────────┐
    │   已執行     │             │     已取消        │
    │ （系統自動） │             │ （標記無法收回）  │
    └──────┬──────┘             └──────────────────┘
           │                             │
           ▼                             ▼
    寫入流水帳                     空間時段釋出
    啟動金流追蹤                   不進入收款流程
```

#### 狀態定義

| 狀態 | 觸發方式 | 後續動作 |
|------|----------|----------|
| 已建立 | 心理師操作 | 佔用空間時段，等待時間到期 |
| 已執行 | 系統自動（隔日結算時，前一日未取消者） | 自動寫入流水帳，啟動金流追蹤 |
| 已取消 | 心理師當日手動 | 釋出空間時段，標記「無法收回」，不進入收款流程 |

---

### 5.4 金流結算時間點

- 系統於**每日執行前一天**的結算，將「已發生日」的預約鎖定進帳
- 心理師若個案當天未到，**必須當天取消**，逾時系統視為已執行
- 若心理師忘記取消，屬於操作疏漏，後果由其承擔，不得事後修改

---

### 5.5 帳務鎖定與修改權限

> **核心原則：** 帳務一旦發生，就不可被基層人員竄改。錯誤應該被看見，而不是被掩蓋。

就像零售門市的收銀邏輯：**店員不能在日結清帳時，回頭修改當日的銷售紀錄。** 帳務的封閉性保證了金流的可信度，錯誤被留在帳面上，才能作為管理檢討的依據。

#### 錯誤追責流程

```
個案未到，但未在當日取消預約
        │
        ▼
系統隔日結算時視為「已執行」，金流產生
        │
        ▼
帳務對不上 → 管理者發現異常
        │
        ▼
管理者追查：心理師未當天取消 or 行政流程疏漏
        │
        ▼
由管理者行使唯一修改權限，並留存完整修改紀錄
```

#### 管理者修改的附加要求

- 每筆修改需填寫**修改原因**
- 系統保留**完整修改紀錄**（原始值、修改後值、時間戳記、操作者）
- 修改紀錄在月報表中獨立呈現，供審查

---

### 5.6 預約提醒機制

系統自動彙整「N 日後門診名單」，提供行政進行電訪確認並記錄溝通結果：

| 結果 | 後續動作 |
|------|----------|
| 已確認 | 個案確認出席，維持預約 |
| 欲取消 | 通知心理師於當日執行取消操作 |
| 未接聽 | 記錄追蹤狀態，待再次聯繫 |

## 六、模組三：諮商流水帳

### 性質
由模組二的預約狀態變為「已執行」時**自動寫入**，無需手動輸入。每筆紀錄以「一個個案、一次諮商」為單位，是財務報表與月報表的**資料底層**。

### 諮商類型

| 類型 | 空間預約 | 說明 |
|------|----------|------|
| 實體諮商 | 需要 | 使用診所實體空間 |
| 線上諮商 | 不需要 | 標記「線上諮商」 |
| 家訪 | 不需要 | 費用由個案或機構直接付給診所，流程同線上諮商 |

### 欄位內容

| 欄位 | 說明 |
|------|------|
| 諮商紀錄 ID | 唯一識別碼，供財務報表連結使用 |
| 預約單號 | 來源預約的編號，永久關聯 |
| 收據號碼 | 收據產製後寫入，格式：I-YYYYMMDD-心理師代號-流水號 |
| 諮商日期與時間 | 來自預約資料 |
| 個案姓名 | 連結至個案管理系統 |
| 負責心理師 | 來自預約資料 |
| 諮商類型 | 實體 / 線上 / 家訪 |
| 使用空間 | 實體填入空間編號；線上與家訪標記對應類型 |
| 收費項目 | 諮商門診 / 心理測驗 / 書籍 / 行政費 |
| 諮商費用金額 | 來自預約資料 |
| 心理師應得酬勞 | 費用 × 70%，自動計算 |
| 診所應得收入 | 費用 × 30%，自動計算 |

### 抽成邏輯

全所統一固定比例：

| 對象 | 比例 | 說明 |
|------|------|------|
| 診所 | 30% | 場地與行政費用 |
| 心理師 | 70% | 諮商酬勞，月結支付 |

### 心理師時間管理
不另設獨立模組，直接從流水帳依需求切片查詢（某心理師工作時段總覽、全所排班密度、各心理師月場次統計等）。

## 七、模組四：空間預約表

### 性質
即時動態表單，與模組二連動：預約建立時自動佔用對應時段，預約取消時自動釋出。**僅適用於實體諮商**，線上諮商與家訪不佔用空間資源。

### 空間概況
- 共三層樓，合計十幾個治療空間
- 各空間有獨立編號與名稱
- 特殊設施標記（如遊戲治療室）

### 前端呈現邏輯

預約表以**日曆格子**形式呈現，每個格子代表「某空間 × 某時段」的交叉點：

- 空白格：可填入預約
- 已填格：顯示心療師名稱，不可覆蓋
- 支援單格填入（單次預約）與連續格填入（批次預約）

### 資料結構（三維邏輯）

| 維度 | 說明 |
|------|------|
| 日期 | 具體日期（橫軸，長度較長） |
| 時段 | 固定時段（如 09:00–10:00） |
| 空間編號 | 對應具體治療空間（縱軸） |

每筆紀錄代表「某日 × 某時段 × 某空間」的使用狀況。資料庫底層以二維表格儲存三個維度鍵值，視覺化呈現由前端介面處理。

### 資料長度管理

- 以**年**或**月**為單位開表，建議一次開兩年，避免跨年銜接問題
- 跨年時需手動建立新表單
- 此為技術層面的管理成本，不影響系統核心邏輯，待技術實作方式確定後再細設計

### 空間利用率
系統自動計算各診間、各時段的稼動率，供管理層決策參考。

## 八、模組五：財務核銷報表

### 性質
追蹤所有個案（自費與機構轉介）的付款與請款狀態，數據從諮商流水帳讀取，以「來源分類」為最高層級結構。

### 執行後的金流分流邏輯

```
已執行
   │
   ├── 自費個案 ──→ 列入「待收款清單」
   │                → 行政確認收訖 → 標記「已收款」
   │
   └── 機構個案 ──→ 列入「該機構請款池」
                    → 行政累積達請款條件後統一送出
                    → 標記「請款中」→ 到帳後標記「已核銷」
```

> 機構個案不一定每診請款，可能累積多筆後統一送出，每筆執行紀錄先進入請款池等待，行政選擇時機批次提出請款。

### 收據系統

| 項目 | 說明 |
|------|------|
| 收據號碼 | 格式：I-YYYYMMDD-心理師代號-流水號 |
| 與預約單號永久關聯 | 確保帳務可追溯 |
| 自動核銷轉單 | 系統抓取「已執行預約單」，一鍵轉換為門診收據 |
| 作廢機制 | 開錯需記錄作廢原因，保留原始編碼軌跡供查帳 |

### 報表層級結構

```
財務核銷報表
│
├── 自費
│   ├── 個案 A
│   │   ├── 第 1 次諮商｜日期｜心理師｜金額｜付款狀態
│   │   ├── 第 2 次諮商｜日期｜心理師｜金額｜付款狀態
│   │   └── 小計
│   └── 個案 B
│       ├── 第 1 次諮商｜日期｜心理師｜金額｜付款狀態
│       └── 小計
│
├── 機構甲
│   ├── 個案 C
│   │   ├── 第 1 次諮商｜日期｜心理師｜金額｜請款狀態
│   │   ├── 第 2 次諮商｜日期｜心理師｜金額｜請款狀態
│   │   ├── 第 3 次諮商｜日期｜心理師｜金額｜請款狀態
│   │   └── 小計
│   └── 個案 D
│       ├── 第 1 次諮商｜日期｜心理師｜金額｜請款狀態
│       └── 小計
│
└── 機構乙
    └── 個案 E
        ├── 第 1 次諮商｜日期｜心理師｜金額｜請款狀態
        └── 小計
```

### 付款狀態標記

| 個案類型 | 狀態欄位 | 狀態流程 |
|----------|----------|----------|
| 自費個案 | 是否已付款 | 未付款 → 已付款 |
| 機構個案 | 請款進度 | 待請款 → 請款中 → 已核銷 |

### 與請款報表範本（Template）串接邏輯
> 後續功能，邏輯預留於此。

1. 系統從核銷報表篩選「待請款」紀錄，依機構分類
2. 自動填入請款範本（個案名稱、諮商次數、日期區間、金額合計等）
3. 產出後可直接列印供簽名
4. 系統記錄「請款日期」作為狀態時間戳記

## 九、模組六：零用金管理

### 制度設計

| 項目 | 內容 |
|------|------|
| 固定水位 | 約 1 萬～2 萬元 |
| 警戒金額 | 低於 3,000 元時觸發補款請款 |

### 支出類型
打掃費、清潔耗材、電費、水費及其他雜項。

### 流程
1. 每筆支出手動記錄（日期、金額、項目、備註）
2. 餘額低於警戒線時彙整明細，向行政單位提出補款申請
3. 申請需附完整支出報表與收據
4. 撥款後補回水位，補款紀錄一併記錄於系統

## 十、模組七：月報表

### 性質
以「月」為單位定期產出，整合前六個模組的數據，呈現診所完整的金流狀況，性質類似公司財務報表。

### 10.1 收入面

| 項目 | 說明 |
|------|------|
| 本月諮商總場次 | 實體 / 線上 / 家訪分別統計 |
| 本月諮商總金額 | 所有場次費用加總 |
| 　└ 自費已收 | 自費個案已付款金額 |
| 　└ 機構已核銷 | 本月完成撥款的機構款項 |
| 　└ 請款中（未到帳） | 已提出請款但尚未收到撥款的金額 |
| 　└ 待請款 | 尚未向機構提出請款的累積金額 |
| 本月取消場次 | 標記「無法收回」的場次數與對應金額 |

### 10.2 支出面——心理師酬勞（月結）

| 項目 | 說明 |
|------|------|
| 本月應付酬勞總額 | 當月所有已執行場次 × 70%，依心理師分列 |
| 　└ 已付款 | 本月已實際支付給心理師的金額 |
| 　└ 待付款 | 尚未支付的應付酬勞 |

**各心理師明細：**

| 心理師 | 本月場次 | 實體／線上／家訪 | 應付酬勞（70%） | 付款狀態 |
|--------|----------|------------------|-----------------|----------|
| 師 A | N 場 | X / X / X | $XXX | 已付／待付 |
| 師 B | N 場 | X / X / X | $XXX | 已付／待付 |

### 10.3 墊付金流分析

機構請款存在金流時間差：諮商完成後需月結支付心理師酬勞，但機構撥款可能延遲數週至數月，此期間由診所先行墊付。

| 項目 | 計算邏輯 |
|------|----------|
| 機構應收未收總額 | 請款中 + 待請款 |
| 對應已付出心理師酬勞 | 上述金額 × 70% |
| **診所目前墊付金額（核心指標）** | 已付酬勞 − 已核銷收入對應酬勞 |

### 10.4 零用金狀況

| 項目 | 說明 |
|------|------|
| 本月零用金支出總額 | 當月雜項支出加總 |

## 十一、模組間連動規則總覽

| 連動關係 | 觸發條件 | 動作 |
|----------|----------|------|
| 預約 → 空間佔用 | 預約建立（實體諮商） | 對應時段空間標記為「佔用」 |
| 預約 → 空間釋出 | 預約狀態變為「已取消」 | 對應時段空間恢復「空閒」 |
| 預約 → 流水帳 | 隔日結算，前一日未取消者自動變為「已執行」 | 自動建立一筆流水帳紀錄，帳務鎖定 |
| 流水帳 → 財務核銷 | 紀錄建立後依經費來源分流 | 進入自費待收款清單或機構請款池 |
| 財務核銷 → 月報表 | 每月結算時 | 彙整所有狀態，產出損益摘要 |
| 個案狀態 → 流失預警 | 超過指定天數未回診 | 產出追蹤清單供行政處理 |
